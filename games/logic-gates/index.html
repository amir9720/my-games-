How to Play Minimalist Logic Gates (500 Circuits)

Minimalist Logic Gates transforms real computer-science Boolean algebra into a sleek, visual dark-mode puzzle across 500 escalating circuit boards. Glowing cyan traces carry a HIGH (1) signal, while dark slate wires carry a LOW (0) signal. Fill each dashed socket with the right gate so every output LED matches its target across all signal test cases simultaneously.

  • Tap to Place or Cycle: Select any gate in the tray below and tap a matching dashed socket (2-IN for binary gates, 1-IN for NOT / PASS). Tap an already-placed socket with the same gate to remove it, or tap with a new gate to swap instantly.
  • Inspect Every Test Vector: Tap the Test 1 / Test 2 / Test 3 / Test 4 pills above the board to switch live input combinations and trace signals through your circuit. A circuit is solved the instant every test pill turns green (✓)!
  • Master All 6 Logic Gates: Start with AND, OR, and NOT in Chapter 1, unlock XOR (outputs 1 when inputs differ) in Chapter 2, NAND in Chapter 3, and NOR in Chapters 4–5. Any logically equivalent gate combination that passes all tests wins!

Game FAQ

Why do some circuits accept more than one gate arrangement?
Just like real digital chip design, Boolean circuits can often be simplified or built in equivalent ways. As long as your completed circuit matches the target outputs across every single Test Case, it passes!
What is the difference between NOT and PASS on a 1-input socket?
NOT is an inverter—it flips 1 → 0 and 0 → 1. PASS is a direct buffer wire that keeps the signal unchanged (1 → 1, 0 → 0).
